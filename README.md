# ThoughtForge for Obsidian

View and edit Markdown notes as mind maps.

Public documentation is being prepared. This snapshot is not a distribution approval.

## Build

Run `npm ci` followed by `npm run build`. The plugin files are `main.js`,
`manifest.json`, and `styles.css` at the repository root.
