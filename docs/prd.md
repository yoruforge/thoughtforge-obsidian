# ThoughtForge（`thoughtforge-obsidian`）企画書・要件定義書（PRD v0.4）

> [!NOTE]
> 本ドキュメントは新規独立 Obsidian プラグイン **ThoughtForge**（リポジトリ: `thoughtforge-obsidian`）の【フェーズ1: 計画】正本です。保存方式は **Markdown 正本（「ノートがそのまま地図」・最小差分・色や座標はノートに書かない）**、UI スタックは **HTML + SVG ハイブリッド ＋ React**、トピックノート本文は **地図ポップオーバーからも直接編集可能**、配布は **Obsidian Community Plugin 公開基準準拠** を前提とします。
> なお、本プロジェクトは **iThoughts（iThoughtsX）** のキーボード中心の操作感に敬意を表して設計した独立オープンソースプロジェクトであり、iThoughts / toketaWare とは無関係・非提携です。記載の製品名は各権利者の商標または登録商標です。YouTube 動画 10 件の機能・UI/UX・デザイン分析の詳細は [ithoughts-youtube-analysis.md](./ithoughts-youtube-analysis.md) を参照してください。

## 1. エグゼクティブサマリー・プロダクトコンセプト

### 1.1 背景と課題

- 定番マインドマップアプリ **iThoughts（iThoughtsX / iThoughts2Go）** は開発が終了しており、「キーボード中心の高速な階層編集」「見やすい自動レイアウトとフォーカス機能」を日常の思考ツールとして使っていたユーザーにとって代替手段が限られている。
- Obsidian 既存の可視化手段には以下のギャップがある。
  - **Markdown 変換系プラグイン**：閲覧中心のものが多く、地図上での双方向・高速キーボード編集や日本語 IME の連続入力に弱い。
  - **Obsidian Canvas**：自由配置や関係線に優れるが、`.canvas`（JSON）が通常ノートと分断され、`Tab` / `Enter` でツリーを素早く伸ばす思考体験とは設計思想が異なる。
  - **外部マインドマップアプリ**：Markdown を取り込むと独自形式（`.itmz` 等）へ複製・変換され、Obsidian のリンク・検索・Git 差分と分断される。

### 1.2 プロダクトビジョン

**「Obsidian の通常ノートが、変換なしでそのまま iThoughts の操作感で編めるマインドマップになる」**

### 1.3 5 つの設計原則

1. **Markdown 正本（Single Source of Truth）**：正本は Vault 内の通常 `.md` ファイルそのもの。独自形式への変換・複製を行わない。
2. **最小差分・非破壊編集（Minimal Diff & Fail-Closed）**：地図からの操作は対象行・対象範囲だけを最小差分で書き戻す。見出し・箇条書き以外の要素（frontmatter、コードブロック、表、Callout 等）は 1 バイトも壊さず保持し、安全に書けない構造では編集を拒否する。
3. **思考を止めないキーボード体験（Keyboard-First & IME-First）**：iThoughtsX 準拠の中核ショートカット体系を採用し、日本語 IME の変換確定と構造操作が誤爆しない体験を最優先する。
4. **見た目とデータの分離**：色・ノード形状・レイアウト座標は Markdown 本文に書かない。階層に応じたスタイルや左右展開は描画エンジン側で表現する。
5. **Obsidian ネイティブとの調和**：リンク（`[[ ]]`）、タグ（`#tag`）、画像埋め込み（`![[ ]]`）、同期（Sync / Git）、全文検索、テーマ、コマンドパレットは Obsidian 本体の仕組みを活かす。

## 2. Markdown ⇄ マインドマップ対応規則

### 2.1 構造マッピング

| Markdown 要素 | マインドマップ上の扱い | 書き戻し原則 |
|---|---|---|
| 最初の H1（`# タイトル`） | **中央テーマ** | タイトルの原文範囲のみ置換 |
| H1 がないノート | ファイル名を中央テーマとして仮表示 | 中央テーマ編集時のみ先頭（frontmatter 直後）に `# タイトル` を追加（ファイル名は変えない） |
| 2 つ目以降の H1、ATX 見出し（`##`〜`######`） | **トピック**（見出しの深さで親子を構築） | 節（次の同等以上の見出し直前まで）を所属範囲として扱う |
| 箇条書き（`-`, `*`, `+`, `1.`, `1)`） | **トピック**（インデントで親子を構築） | 元のリスト記号・インデント幅を保持して最小差分編集 |
| トピック直下の連続段落 | **トピックノート**（詳細本文） | タイトル行とは分離して保持・ポップオーバーから直接編集可能 |
| インライン記法（`[[ ]]`, `![[ ]]`, `#tag`, 装飾） | タイトル内の属性・リンクとして解釈 | 編集時は原文のまま編集欄に出し、書式を失わせない |
| タスク記号（`[ ]` / `[x]`）、行末ブロック ID（`^id`） | タイトル原文範囲の外側として保護 | タイトル編集前後で元の記号・ID を維持 |

### 2.2 未対応ブロックの保全

frontmatter、フェンス／インデントコードブロック、表、引用、Callout、数式ブロック（`$$`）、HTML ブロック、水平線、脚注定義、リンク参照定義、Obsidian コメント（`%% %%`）はトピック化せず、最も近い親トピックに紐づけて 1 バイトも変えず保持する。

### 2.3 安全停止（Fail-Closed）条件

- **地図で開かない**：2MB 超、5,000 トピック超、閉じない frontmatter。
- **読み取り専用**：改行コード混在（CRLF/LF/単独 CR）、同一リスト内のタブ・スペース混在、箇条書き内の見出し、構文破損による範囲重複・未分類行。

## 3. 機能一覧と MVP スコープ

- **Phase 1（MVP：M0〜M3）**：
  - **閲覧＆レイアウト・ビジュアル（M1 / M2-ui）**：マップビュー起動、Markdown 並置・ソース行ジャンプ、レイアウト切替（左右バランス / 右片側 / トップダウン組織図）、階層 0〜9 テーマ・テーパード有機曲線＆下線ベースライン接続・パステルティント／ワイヤーフレーム／モノクロカラーモード・レインボー配色・背景グリッド、マップ内 Quick Style Popover、折りたたみ（`.`）・深度 `0〜9`、Zoom/Pan/全体フィット・選択フィット（`⌘⇧0`）・選択ノード自動追従、Focus（固定/追従）、Quick Filter＋Markdown 由来構造化フィルタ（ノート有・タスク状態・リンク・`#tag`・保全ブロック）、SVG バッジ＆ノートホバークイックプレビュー、非破壊トピック番号付け表示、語数・ズーム・Styles 統合ステータスバー、リンク起動、コマンドパレット登録。
  - **双方向編集＆安全保護（M2-a / M2-b / M2-c・M3）**：Classic Keymap 全操作（M2-a: `F2`・`Tab`・`Enter`・`Shift+Enter`／M2-b: `Shift+Tab` 新親・`Delete` 枝削除・`Cmd+Backspace` 子昇格削除・`Cmd+Arrow` 並替/昇降・`Cmd+Enter` 分割・`Cmd+Z/Shift+Z` Undo/Redo・タスク `[ ]`↔`[x]` クリックトグル）、日本語 IME ガード、未保存 Markdown 競合保護、および M2-c / M3 での `DraftStore`（`field: 'title' | 'note'` 下書き退避・回復）と同時公開するトピックノート直接編集（`Cmd+Shift+T`）・マウス/D&D 再配置・並替・枝コピペ。
- **Phase 2（Obsidian 強化：M4）**：リンクによる地図間移動＆履歴バック、Backlinks カード、画像 `![[ ]]` サムネイル・タグ `#tag` 連携、カーソル位置から地図へ、枝のノート切り出し、`NodeMetadataProvider` サイドカーによる非破壊視覚拡張（Boundary / Relationship / 個別色・アイコンの検討。Markdown 本文へは書かない）。
- **Phase 3（拡張：M5）**：ブランチ順の簡易プレゼンテーションモード（全体→各主要枝の滑らかなズーム遷移）、SVG/PNG/OPML 出力、`.itmz` 片方向インポート、Canvas 出力、モバイル検討。
- **対象外**：Markdown への自由座標・色・形保存、独自タスク属性（Effort/Cost/Resources/Rollup 等）の独自書式書込み、手書き Doodle、内蔵 Web リサーチ、独自同期/共有、Office 出力、常設 Outline/右パネル。

## 5. 確定済みの設計方針

1. リポジトリ・ブランディング方針：リポジトリ／ディレクトリ名は `thoughtforge-obsidian` とする。`manifest.json` の `id` / `name` には他社製品名（`iThoughts` 等）および `obsidian` を含めず固有ブランド（`ThoughtForge` 系）へ統一する（`id` は小文字とハイフンのみ、末尾 `plugin` 不可）。iThoughts へのリスペクト表記は `README.md`・`docs/prd.md` に限定し、非提携・商標帰属の免責を必ず併記する
2. トピックノート本文：地図ポップオーバーからも直接編集可能（ブロック構文誤入力ガード・字下げ保持・`field: 'note'` 下書き保護必須）
3. 描画・UI スタック：HTML + SVG ハイブリッド ＋ React 19（ビューポートカリング併用）
4. `.itmz` インポート：Phase 3（M5）
5. 配布ターゲット：最初から Obsidian Community Plugin 公開基準準拠（ja/en i18n、Desktop 3 OS 配慮）
